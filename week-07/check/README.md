# week-06 확인 도구

이번 주 앱(바깥 정보를 받아 오는, 폰에 설치되는 앱)이 규칙을 지키는지 파일을 읽어서 확인해요.
따로 설치할 것은 없고 Node.js 만 있으면 돼요.

## 쓰는 법
맨 위 작업실 폴더에서:

```
node week-06/check/check.js              # week-06 폴더 전체
node week-06/check/check.js week-06/앱폴더  # 한 폴더만
```

## 확인하는 것
1. API 키·비밀번호가 파일에 적혀 있지 않은가 (`.env` 파일, 키를 값으로 적은 곳, 주소 속 키)
2. 전화번호·주소·학교 이름이 없는가
3. 화면 기본: 제목, 폰 화면 크기 설정(viewport), 한국어 페이지
4. 바깥 정보 받아 오기: `fetch` 가 있는지, 실패를 잡는지(`catch`), 서버 응답을 확인하는지(`res.ok`), 인터넷이 끊긴 경우, https 주소인지
5. 폰에 설치되는 앱: manifest(이름·시작 주소·display·192/512 아이콘), 서비스 워커

## 결과 읽는 법
- ✅ 됐어요 · ❌ 고쳐야 해요 · ⚠️ 고치면 더 좋아요
- ❌ 가 하나라도 있으면 "고칠 것 N개" 로 끝나요.

## 이 도구가 못 하는 것
파일만 읽어서 확인해요. 진짜로 폰에 설치되는지, 인터넷을 끄면 까닭이 화면에 나오는지는 직접 해 봐야 알아요.
