# week-07 확인 도구

이번 주 작품(그림 그려서 올리는 사이트)이 이번 주 규칙을 지키는지 파일을 읽어서 확인해요.
따로 설치할 것은 없고 Node.js 만 있으면 돼요.

## 쓰는 법
맨 위 작업실 폴더에서:

```
node week-07/check/check.js                # week-07 폴더 전체
node week-07/check/check.js week-07/폴더이름  # 한 폴더만
```

## 확인하는 것
1. API 키·비밀번호가 파일에 적혀 있지 않은가 (`.env` 파일, 키를 값으로 적은 곳, 주소 속 키)
2. 전화번호·주소·학교 이름이 없는가
3. 화면 기본: 제목, 폰 화면 크기 설정(viewport), 한국어 페이지
4. 저장하는 코드가 `storage.js` 한곳에 모여 있는가 (`localStorage` 등이 다른 파일에 있으면 ❌), 바깥 서버로 보내는 코드(`fetch` 등)가 없는가
5. 로그인은 자리만 있는가: 화면 위쪽에 "로그인 자리" 칸이 있고, 비밀번호 칸이나 로그인 코드는 아직 없는가
6. 반응형: 화면 폭에 따라 바뀌는 규칙(`@media`, 줄바꿈 flex), 그림이 `width: 100%` 로 폭에 맞춤
7. `CLAUDE.md` 기능 표에서 "넣었음" 인 기능이 코드에 실제로 있는가 (새 기능을 표에 넣으면 이 도구의 `FEATURE_HINTS` 도 맞춰 두기)

## 결과 읽는 법
- ✅ 됐어요 · ❌ 고쳐야 해요 · ⚠️ 고치면 더 좋아요
- ❌ 가 하나라도 있으면 "고칠 것 N개" 로 끝나요.

## 이 도구가 못 하는 것
파일만 읽어서 확인해요. 그림이 실제로 그려지는지, 폰에서 잘리지 않는지는 직접 열어 봐야 알아요.

## 나중에 로그인과 보관함을 붙일 때
4번(바깥으로 보내는 코드)과 5번(로그인 코드 없음) 검사는 "아직 안 만든다" 는 규칙이라 ❌ 가 나와요.
그때 이 두 검사를 바꾸거나 빼야 해요.
