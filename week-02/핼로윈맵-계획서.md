# 🎃 핼로윈 콘테스트 맵 계획서 (판타지 + 공포)

## 정해진 것
| 번호 | 항목 | 내용 |
|---|---|---|
| 1 | 만드는 곳 | 웹 게임 (브라우저에서 돌아가는 HTML) |
| 2 | 이야기 | 주인공은 **퇴마사**. 사후세계를 관리하는 사람들과도 만나서 이야기할 수 있음 |
| 3 | 공포 방식 | 몬스터가 있어서 **분위기가 무서워지는 것**. 점프스케어 없음 |
| 4 | 조작 | WASD 로 움직임 (W 위, S 아래, A 왼쪽, D 오른쪽). 점프나 웅크리기 없음 |
| 4 | 진행 | 계속 앞으로 나아감. 갈수록 귀신·유령 몬스터가 더 자주 나옴 |
| 4 | 전투 | 몬스터를 공격해서 퇴마 → 포인트를 얻음 |
| 4 | 포인트 | 몬스터가 셀수록 포인트를 많이 줌. 포인트는 2종류 이상 |
| 4 | 강한 몬스터 | 어느 정도 이상 강한 몬스터는 그 몬스터만 주는 **특이 포인트**나 **스킬**이 있음 |
| 4 | 세이브 포인트 | 몬스터가 안 나오는 쉬는 구간. 원하면 **사후세계**로 갈 수 있음 |
| 4 | 사후세계 | NPC 에게 포인트를 내고 무기 사기, 스킬 배우기, 강화하기. 잡은 강한 몬스터의 스킬 얻기 |
| 5 | 결말 | 최종 보스 **악귀**를 퇴마하면 스토리가 끝남 |
| 6 | 길이 | 스토리를 끝낸 뒤 원하면 **엔드리스 모드**로 계속 플레이 |
| 7 | 콘테스트 조건 | 없음 |

| 8 | 화면 | 옆에서 보기. 길이 넓어서 W/S 로 위아래를 넉넉하게 움직임 |
| 9 | 나아가기 | 내가 걷는 만큼만 화면이 따라옴 (빨리 가도 되고, 남아서 사냥해도 됨) |
| 10 | 공격 | 마우스 클릭. 마우스 쪽으로 공격하고, 무기나 설정한 스킬에 따라 달라짐 |
| 11 | 포인트 3종 | 혼불(흔함, 무기) · 망자의 눈물(귀신류, 스킬) · 원념 조각(강한 귀신, 강화) — Claude 가 정함 |
| 12 | 바 | 체력 바 + 영력(공격 스테미나) 바. 영력이 적으면 귀신류에게 피해가 매우 덜 들어감 (좀비·해골은 상관없음) |
| 12 | 죽으면 | 마지막 세이브 포인트에서 다시 시작, 혼불 30% 잃음 — 답이 없어서 Claude 가 정함 |
| 13 | NPC | 저승사자(무기) · 망자 도서관 사서(스킬) · 영혼 대장장이(강화). 대사 한 줄씩 |
| 14 | 그림 | 도트 말고, Claude 가 코드로 그림 |
| 15 | 1차 범위 | 2단계: 이동 + 공격 + 몬스터 + 포인트 + 세이브 포인트 + 사후세계 상점 |
